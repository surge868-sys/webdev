# webdev

Web development playground — lives in the cloud on GitHub, ready to work on from anywhere.

## Stack

- [Next.js](https://nextjs.org) (App Router)
- TypeScript
- Tailwind CSS
- ESLint

## Getting started

```bash
npm install
npm run dev
```

Open http://localhost:3000 — edit `src/app/page.tsx` and the page hot-reloads.

## Commands

| Command         | What it does                            |
| --------------- | --------------------------------------- |
| `npm run dev`   | Start the local dev server (Turbopack)  |
| `npm run build` | Production build                        |
| `npm start`     | Serve the production build              |
| `npm run lint`  | Lint the code                           |

## Layout

- `src/app/` — pages, layouts, and global styles (App Router)
- `public/` — static assets served from the site root
